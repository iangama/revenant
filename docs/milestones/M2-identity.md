# M2 — Identity

Status: complete and validated locally.

## Scope

- Development-only local username authentication
- `AuthRequest` and `AuthResponse`
- `CharacterListRequest` and `CharacterListResponse`
- One deterministic level-one Operator per valid local account
- Ordered connection state enforced by the gateway
- End-to-end coverage through `revenant-bot` and Godot

There are no passwords, OAuth providers, persistence, world joins, or gameplay in M2.
