# Revenant closed playtest — participant instructions

This session tests the software, not you. There is no expected skill level and
you may stop at any time.

1. The operator will start the reviewed local package after confirming your
   consent choices.
2. Start Revenant and play until you believe the session is finished.
3. You may open Settings whenever you want. Choose the display, guidance,
   audio, and reduced-flash options that are comfortable for you.
4. If the application closes, freezes, disconnects, or shows Retry, stop and
   tell the operator. Retry always begins a new activity; no progress is
   resumed.
5. Do not troubleshoot the gateway or database yourself. The operator will
   confirm service health before another attempt.
6. After play, answer the short questions in your own words. There are no
   correct answers.

The optional local observation report records only the anonymous participant
code, package identity, display/preferences, a few first-occurrence timings,
enumerated outcomes, and a bounded cooldown count. It records no name, email,
password, IP, raw key history, pointer trail, voice, video, or screen recording,
and it is never uploaded automatically.

You may decline observation, separately decline retention, request deletion,
or end participation without giving a reason. Keep the package on the operator's
machine and do not redistribute it.
